# Optimización inferencial del rendimiento agrícola

Proyecto integrador INC-2505: dashboard de análisis de rendimiento y eficiencia de riego en cultivos de invernadero.

- `app.py`: aplicación Streamlit.
- `requirements.txt`: dependencias.
- `Informe_Tecnico.md`: informe técnico y guía de despliegue.

Ejecuta localmente con `pip install -r requirements.txt` y `streamlit run app.py`.
